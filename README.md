

\# AI Spam Message Detector



\## Project Overview

A Machine Learning project that classifies SMS messages as Spam or Normal (Ham).



\## Objective

Analyze SMS data, identify message patterns, evaluate a classification model, and build an interactive dashboard.



\## Tools and Technologies

\- Python

\- Pandas

\- Scikit-learn

\- Matplotlib

\- Streamlit

\- Jupyter Notebook



\## Dataset

SMS Spam Collection dataset with labeled spam and ham messages.



\## Key Features

\- Exploratory Data Analysis

\- Spam vs Normal message distribution

\- Average message length analysis

\- Live SMS classification

\- Spam probability estimate

\- Model performance metrics and confusion matrix



\## Model

Logistic Regression with text features prepared during training.



\## Previously Recorded Results

\- Accuracy: 97.58%

\- Spam Precision: 90%

\- Spam Recall: 92%

\- Spam F1-score: 91%



Note: These are results recorded during notebook evaluation. Final performance should be verified on a genuinely independent test dataset.
